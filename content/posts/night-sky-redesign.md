上一篇把站搭起来了，这一篇记怎么把它变成现在的样子：先是氛围，其次才是博客。

## 想要的样子

最早是纸墨风的排版，干净，但没有情绪。后来想要的是《小王子》那样的夜空：安静，有一点治愈。落到页面上是三件事：

- **启动页**：夜里的草坡，一个人背对屏幕坐着看星星，流星不断划过。点一下，进入星空。
- **星海**：首页第一屏是一片星空，每篇文章是一颗星，沿一条「时间之河」从过去流向今天。旅人站在今天，碰哪颗星，他就飞回那一天。
- **处处是夜空**：每一页的背景都有闪烁的星和流星，鼠标划过留一道很淡的星轨，点一下会绽开一团星光。

约束沿用原来的：Hugo + PaperMod，不改主题目录，不引入构建链和 CDN，只有模板、CSS 和几段内联 JS。人物、草坡用内联 SVG，星空和草用 canvas 画，一张图片都没有。

## 几个实现上的决定

**星星的位置在构建时算好。** 不靠 JS 排版，而是在 Hugo 模板里用 `math.Sin`、`math.Log` 算出坐标，写进内联的 CSS 变量，没有 JS 也能看到星星。两篇文章隔得越久，星星离得越远；间距按天数取对数，免得一年的空白把画面拉断：

```go-html-template
{{- $days := div (float (sub $p.Date.Unix $prevU)) 86400.0 }}
{{- $acc = add $acc (add 0.6 (math.Min 1.6 (div (math.Log (add 1.0 $days)) 2.302585))) }}
```

河的形状只在一个 partial 里定义，用 `return` 返回坐标。星星的位置和画布上的河都从这里取值，改形状只改一处。

**启动页在首帧之前决定要不要出现。** `<head>` 里一小段脚本先看 `sessionStorage`，需要时给 `<html>` 加一个 class，CSS 据此盖住整页。这样不会先闪一下正文再盖上。每个标签页只出现一次；没有 JS 的访客直接看到星海。

**画布分两层。** 静止的星场和银河只在窗口尺寸变化时画一次，滚动时整块画布用 `transform` 平移一点，做出一点纵深；闪烁的星和流星画在另一块透明画布上，每帧只画这几十个小东西。随机数用固定种子，所以每一页看到的是同一片天。

## 三个坑

| 现象 | 原因 | 解决 |
|:--|:--|:--|
| 鼠标星轨和流星「没效果」 | 系统关了动画，浏览器报告「减少动效」，代码照办了 | 加一个网站自己的动效开关 |
| 只留暗色以后，列表页变灰 | PaperMod 的 `[data-theme="dark"]` 优先级更高 | 色板选择器带上同样的属性 |
| 八九月的文章会让构建失败 | `int "09"` 被当成八进制 | 去掉前导零，不转整数 |

**第一，「没效果」其实是系统设置。** 我的 Ubuntu 里 GNOME 的 `enable-animations` 是 `false`，Firefox 会据此把 `prefers-reduced-motion` 报成 `reduce`。星轨脚本第一行就尊重了这个设置直接退出，所以在自己电脑上什么都看不到；而用无头 Chromium 截图测试时，它默认不减少动效，一切正常。两种状态都要测。

直接无视这个设置也不对，有人是真的需要它。最后的做法是在顶栏放一个四角星按钮：没点过就跟随系统，点过就记在 `localStorage` 里。`<head>` 里的脚本在首帧之前把结果写成 `<html class="calm">`，CSS 里所有安静态都挂在这个 class 上；没有 JS 时退回媒体查询：

```css
html.calm .meteor { display: none; }

@media (prefers-reduced-motion: reduce) {
    html:not(.js-motion) .meteor { display: none; }
}
```

安静态也不是空白：流星定格成几道光痕，星轨和点击的星光只在原地淡出。

**第二，选择器优先级。** 去掉浅色主题时，我把色板合并成一个 `:root {}`，结果归档、标签这些列表页变成了 PaperMod 默认的灰。主题自己写的是 `:root[data-theme="dark"]`，多一个属性选择器，优先级比 `:root` 高。改成同样的选择器，并且排在主题样式后面加载：

```css
:root,
:root[data-theme="dark"] {
    --paper: #0a0e1c;
    /* … */
}
```

**第三，`int "09"`。** 归档页按月分组时写了 `{{ $month := int .Key }}`，`.Key` 是 `"01"` 到 `"12"` 的字符串。Hugo 的 `int` 会把前导零当成八进制前缀，`"08"`、`"09"` 不是合法的八进制数，构建直接报错。十一月的文章不会触发，用一批假文章压测时才撞上。月份只用来显示，所以改成 `strings.TrimPrefix "0" .Key`。

## 怎么验证

每次改完跑三件事：

```bash
hugo --gc --minify --destination /tmp/out                              # 零 ERROR
grep -rE "https?://(fonts|cdn|unpkg|jsdelivr)" /tmp/out                # 无外链
grep -rhoE "font-size: 0\.[0-6][0-9]*rem" assets/css/extended/*.css    # 无过小字号
```

再用 Playwright 在 1440 和 390 两个宽度下截图，量 `scrollWidth` 确认没有横向滚动，动效开关开、关各看一次。流星多不多也是量出来的：给背景画布的 `createLinearGradient` 计数，每颗流星每帧会调用它，十五秒里数到七颗。
